# Moraga Gas & Nick's Auto Service

Website for **Moraga Gas** and **Nick's Auto Service**, at 1410 Moraga Rd, Moraga, CA 94556.

The whole site is one file, `index.html`, with no build step. Open it in a browser, or host it on any static host (Netlify, Cloudflare Pages, GitHub Pages).

## Editing

Phone numbers, hours, octane grades, services and the booking email are all in the `SITE` settings block near the bottom of `index.html`.

## Booking form

Appointment requests are emailed to the address in `SITE.bookingEmail` through [FormSubmit](https://formsubmit.co). The first submission from the live site sends an activation email to that inbox, and bookings are delivered only after you click its link.

## Files

- `index.html`: the site (the logo is embedded in it)
- `assets/logo-moraga-gas.png`: the Moraga Gas logo with its background removed, for reuse
